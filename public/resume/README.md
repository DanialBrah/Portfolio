# Resume

Place the CV PDF here, named exactly:

```text
MohdDanialHakim-CV.pdf
```

The "Download CV" buttons on the home hero and the About page link to
`/resume/MohdDanialHakim-CV.pdf`. Until the file exists those links 404.

To use a different filename, update `resumePath` in `src/config/site.ts`.

> Files in `public/` are copied to the build output as-is and are publicly
> reachable — do not put anything here you would not want indexed.
